# Student Internship Management System

A full-stack system for managing student internships.

## Project Structure

- backend – Spring Boot REST API (AI recommendations + RSS feed)
- student-frontend – Angular application for students
- faculty-app – JSP application for faculty administration
- company-app – JSP application for companies
- database – SQL schema and seed data
- docs – Documentation and diagrams

## Technologies

- Spring Boot
- MySQL 
- Angular
- JSP (Maven)
- Gemini AI API
